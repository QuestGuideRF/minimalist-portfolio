# Minimalist Portfolio

Простой и элегантный одностраничный портфолио с минималистичным дизайном. Идеально подходит для демонстрации ваших навыков, опыта и проектов.

## Описание

Минималистичное портфолио с двухколоночной сеткой, созданное с использованием чистого HTML и CSS. Проект использует современные CSS Grid технологии для создания адаптивного макета, который отлично выглядит на всех устройствах.

## ✨ Особенности

- Минималистичный и чистый дизайн
- Адаптивная верстка (Desktop, Tablet, Mobile)
- Двухколоночная сетка с использованием CSS Grid
- Плавные hover-эффекты
- Темная цветовая схема
- Легкая настройка и кастомизация

## 🚀 Быстрый старт

1. Откройте файл `index.html` в вашем браузере
2. Или используйте любой локальный веб-сервер:
   ```bash
   # Python 3
   python -m http.server 8000

   # Node.js (http-server)
   npx http-server
   ```

## 🛠 Использование

### Настройка контента

Откройте `index.html` и измените:

- **Личная информация**: Имя, город, страна (строки 15-16)
- **Социальные сети**: Ссылки на Twitter, LinkedIn, GitHub (строки 17-19)
- **О себе**: Текст в секции "About" (строка 23)
- **Опыт**: Текст в секции "Experience" (строка 25)
- **Навыки**: Текст в секции "Skills" (строка 28)
- **Проекты**: Ссылки на ваши проекты (строки 30-34)
- **Контакты**: Email адрес (строка 36)

### Настройка стилей

Откройте `style.css` для изменения:

- Цветовой схемы (строки 13-14)
- Шрифтов (строка 12)
- Размеров и отступов
- Адаптивных breakpoints (строка 91)

## 🧪 Технологии

- **HTML5** - Разметка
- **CSS3** - Стилизация (Grid, Flexbox, Media Queries)
- **Font Awesome** - Иконки социальных сетей
- **Google Fonts** - Шрифт Roboto
